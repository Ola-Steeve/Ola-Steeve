## Hi, I'm Ola 👋

Security engineer working across cloud security, identity and access, detection and incident response. I came up through cloud engineering and DevOps before moving into security, so I harden infrastructure as someone who has built it.

**Recently:** at Zenith Bank — Nigeria's largest bank by tier-1 capital — I led the firewall remediation that cleared a long-standing PCI DSS audit finding, built privileged access across hundreds of servers, corrected a network access control that was detecting threats but not blocking them, and ran SIEM detection and incident response for systems serving 40 million customers.

**Now:** finishing an M.Eng at Concordia, where my work has moved toward AI — multi-agent systems that triage security alerts under guardrails, machine-learning intrusion detection, and software supply-chain security.

### Selected work

- **Multi-agent AI for security operations** — LLM agents that triage and investigate alerts with human-in-the-loop approval, sandboxed execution, validated outputs and tamper-evident audit trails; adversarially tested for prompt injection and unsafe tool permissions.
- **ML intrusion detection at scale** — detection models over 2.8M network flows (CICIDS2017) at 95–99% accuracy, with PCA-reduced feature space.
